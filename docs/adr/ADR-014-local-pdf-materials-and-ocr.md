# ADR-014｜首页材料、本地 PDF 与 OCR 的受控入口

- 状态：按 2026-11-06 用户授权实施；正式验收逐项留原 Linear 卡。
- 责任：DEV-1733/1609/1610/1611/1614/1615；OCR 归 DEV-1649，选材外发归 DEV-1651。

首页和任务共用一个文件入口。原件经选择器或真实拖放进入受控暂存，再由 Application 提交不可变副本与 SQLite 来源关联。用户原路径不保存、不回传；接收端校验大小、文件头、符号链接和哈希。先落位并同步文件，再提交来源和幂等结果；未知回执通过原 token 查询/重试，原件不覆盖。

首页首份材料创建独立 Task，home 仅作为当前材料组的界面指针。用户可明确开始新材料组；原任务和原件继续保留。聊天 Run 的 home 是展示作用域，选材 manifest 仍绑定唯一 Task。任务页面只能读取自己材料。材料卡移除只改变本次选材，不删除原件。

PDF.js 阅读当前固定版本。后台 PDF.js 在无 preload、无 Node 的隔离窗口逐页提取和渲染；只由宿主传入受控原件字节，不接受业务 Renderer 提交的任意图像作为 OCR 来源。Apple Vision 辅助程序从 stdin 接收页面 PNG，stdout 返回文字和实际坐标/置信度。无网络、无 Key，串行识别、页级检查点、取消后拒收迟到结果。新识别建立派生版本，旧结果保留。首版回看承诺物理页级，区域证据不冒称精确文字 Anchor。

文字层可靠时直接提取；疑似扫描页明确显示待识别，用户主动启动本地 OCR。混合页面保留强制重新识别入口，不能假设有少量文字就覆盖整页。正文与 OCR 派生物分开保存，不把识别结果当律师核实事实。

选材预览由 Application 从固定来源/派生版本生成；指令最多 4000 字符，材料上下文另设 32000 字符总预算。超限拒绝并要求缩小页范围，不静默截断。发送仅引用固化 manifest，模型、指令、作用域及版本变化均重新确认；不开放 Shell、任意文件 Tool 或新增 Pi Runtime。正文与文件中的指令仅为待分析资料。

本机阅读/OCR 与云端推理分别计量。首版不实现 MinerU 外发，不导出带文字层的新 PDF，不宣称复杂表格结构和手写全覆盖。新增表采用追加迁移，不改旧数据；撤销 UI/运行入口后仍保留用户新增文件与数据库，回退不能直接降级打开不兼容的新库。

阅读器显式关闭 react-pdf 11 的 Document/Page Suspense，避免首挂载时复制字节导致缓存身份重建并反复创建 Worker。图片解码限制 16 MP、严格超限失败；画布限制 8 MP，先获取当前页尺寸再挂载 Page。后台打开期限 30 秒，整份处理 15 分钟；取消在打开阶段即生效。

## 2026-11-06 用户交互修订：附件随一次发送自动准备

用户明确要求用聊天附件流程替代手动保存、OCR、勾选及二次预览。当前附件卡与所选模型是发送范围；一次点击发送冻结指令与这些附件，后台等待导入并生成不可变输入清单。输入可在准备期间继续编辑，成功回执只清理本轮快照，不清除后来输入。导入/准备失败不降级为纯文字发送；未知收费回执保留原 Run ID，只有查询或同 ID 核对，不自动另发。

文字 PDF 读取文字层；疑似扫描/混合页在 gpt-4.1-mini、deepseek-flash 下由隔离 PDF.js 渲染，以 Pi ImageContent 与提示词同次请求完成视觉阅读和分析。deepseek-v4-pro 当前 Pi 模型表仅支持文字，自动采用既有本地 Vision。不得默换模型、调用额外收费 OCR 或自动把全文/旧附件带入下一轮。视觉结果不是可检索的本地 OCR 派生文本，更不是已核验事实。

复用 material_previews 记录固定来源、物理页、渲染配置及图像摘要，图像不存入消息/SQLite；派发前从受管原件重建并验证摘要。最多 12 张扫描页、合计 24 MiB base64、文字 32,000 字符；超限明确失败，不能静默漏页。只保留现有 Pi Runtime；发送后的附件名称/来源/页码从 Application 清单投影到 Run，旧 Run 可无此字段，原件可从消息回看。

参考机制（未复制源码）：OpenAI File Uploads FAQ、Claude Upload files to Claude、DeepSeek Vision 官方文档（2026-11-06），以及已安装 Pi AI 1.5.0 模型表与 Agent.prompt(input, images)。工程校验、合成 Provider 与真实 Key 质量/费用分别留证。

阅读器保留无需 Key 的离线文字提取与停止，材料“更多”保留原件恢复，均非日常发送前置。恢复暂存持久保留 restore_source_id，失败/未知后按同 token/目标恢复；commit拒绝把恢复暂存变成新导入。界面读取诊断与导入阻断分开，不能因历史阅读错误永久阻止已恢复附件发送。
