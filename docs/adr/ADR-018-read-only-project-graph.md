# ADR-018｜项目关系图的只读投影

状态：验证中。实施范围见 [DEV-1802](https://linear.app/logixy-ai/issue/DEV-1802)。

## 首版决定（2026-11-12 前）

采用 [React Flow](https://github.com/xyflow/xyflow) 发布包 `@xyflow/react@12.12.1`（MIT，React 19 满足 peer 范围）。它提供画布、缩放和键盘聚焦。CaseLite 自行决定节点、可点击目标和关系。与手写 SVG 相比，可复用缩放、定位及焦点行为。自动布局和可编辑图谱留待真实需求明确。

项目、任务、文档仍由原 Application/SQLite 负责。图仅消费当前项目已读数据，既不存储节点，也不写关系。禁止拖动节点、连线、删除和关系推断。样式通过已有打包入口发射，沿用现行 CSP。

撤销 DEV-1802 提交可回到原占位栏，无需迁移。跨项目、证据关系、权限和大图规模均需重新验证。

已核对 d3 系列锁定安装包的 ISC/BSD-3-Clause 全文，逐包精确准入并随安装包提供 THIRD-PARTY-GRAPH-NOTICES。Zustand 为 React Flow 的内部传递依赖，CaseLite 页面不直接使用。

## 2026-11-12｜VISUAL-C-20261112-R2 有限修订

依据 DEV-1802 的 `VISUAL-C-20261112-R2` 用户决定，首版中“禁止拖动节点”的展示限制已被纯坐标交互替代。首版的只读业务边界和其余历史决定继续保留。

当前只允许在当前窗口、当前图视图内拖动节点坐标，使用既有重新排布预览、取消、应用及坐标撤销重做，并在切换视图时保留当前位置、选择和视口。单击只选择节点并显示属性；双击经原入口打开对应任务或文档。虚构示例没有真实目的地，不能作为项目记录打开。布局只在窗口内的投影状态中保存，不承诺跨重启或组件卸载持久化。

项目、任务、文档及其归属仍由原 Application/SQLite 负责，业务对象和关系继续只读。禁止新增、重连或删除关系，禁止从布局、选择或图示推断法律事实。数据 Owner、现有 IPC 边界、CSP、许可和依赖均不因本次有限修订改变。

首版留待真实需求的“自动布局”仅表示不授权新增自动布局引擎或专业关系编辑，不否定已经批准的既有排布操作。本次修订状态仍为验证中，原生交互和独立验收另行记录。
