# ADR-018｜项目关系图的只读投影

状态：验证中。实施范围见 [DEV-1802](https://linear.app/logixy-ai/issue/DEV-1802)。

## 首版决定（2026-11-12 前）

采用 [React Flow](https://github.com/xyflow/xyflow) 发布包 `@xyflow/react@12.12.1`（MIT，React 19 满足 peer 范围）。它提供画布、缩放和键盘聚焦。CaseLite 自行决定节点、可点击目标和关系。与手写 SVG 相比，可复用缩放、定位及焦点行为。自动布局和可编辑图谱留待真实需求明确。

项目、任务、文档仍由原 Application/SQLite 负责。图仅消费当前项目已读数据，既不存储节点，也不写关系。禁止拖动节点、连线、删除和关系推断。样式通过已有打包入口发射，沿用现行 CSP。

撤销 DEV-1802 提交可回到原占位栏，无需迁移。跨项目、证据关系、权限和大图规模均需重新验证。

已核对 d3 系列锁定安装包的 ISC/BSD-3-Clause 全文，逐包精确准入并随安装包提供 THIRD-PARTY-GRAPH-NOTICES。Zustand 为 React Flow 的内部传递依赖，CaseLite 页面不直接使用。

## 2026-11-12｜VISUAL-C-20261112-R2 有限修订

依据 DEV-1802 的 `VISUAL-C-20261112-R2` 用户决定，首版中“禁止拖动节点”的展示限制已被纯坐标交互替代。首版的只读业务边界和其余历史决定继续保留。

当前只允许在当前窗口、当前图视图内拖动节点坐标，使用既有重新排布预览、取消、应用及坐标撤销重做，并在切换视图时保留当前位置、选择和视口。单击只选择节点并显示属性；双击经原入口打开对应任务或文档。虚构示例没有真实目的地，不能作为项目记录打开。布局只在窗口内的投影状态中保存，不承诺跨重启或组件卸载持久化。

项目、任务、文档及其归属仍由原 Application/SQLite 负责，业务对象和关系继续只读。禁止新增、重连或删除关系，禁止从布局、选择或图示推断法律事实。数据 Owner、现有 IPC 边界、CSP、许可和依赖均不因本次有限修订改变。

首版留待真实需求的“自动布局”仅表示不授权新增自动布局引擎或专业关系编辑，不否定已经批准的既有排布操作。本次修订状态仍为验证中，原生交互和独立验收另行记录。

## 2026-11-13｜VIZ-V1-DEV1910-A-20261113 显示配置持久化

依据 DEV-1910 顶部同名批准切片与已批准 V1 文档 `38c47045-0328-4c9b-9d4c-524389b78d10`，延续原项目—任务—可编辑文档归属投影，只在原 SQLite 增加每项目一份 `current` 显示配置。业务对象、归属边、正文、固定来源和旧快照仍只读；不新增事实/来源库或 Runtime。项目字段沿项目修订；文档标题来自 Task，单独携带 Task.version，元数据修订和正文修订分别携带。

原 Catalog typed 入口经 Application 使用原连接和宿主 workspace；图查询 depth 1/2、最多200节点，同一读事务先有界取任务，再取剩余额度的未归档文档，多取一行判断截断，不读全库后截断。保存与重开固定使用 depth2/200 同一投影及宿主指纹；指纹含范围、所有已读字段、Owner修订和归档状态，不含正文、路径或真实材料副本。

新表仅保存白名单显示配置、format_version=1及递增revision；revision0为无写入默认。允许 network/grouped/list、kind/none分组、full/compact标签、可见种类、隐藏对象ID、有界有限坐标/视口、选择和最多160字自定义显示标签；各对象数组最多200，引用只允许当前有界投影内真实typed ID。样例、任意JSON、业务字段和正文不能保存。读配置时按当前可读投影裁剪已移出/归档文档的引用及标签，保留原历史记录，明确scope_pruned；项目归档只读，跨workspace/project拒绝。

保存用 expected_view_revision、expected_source_fingerprint和原幂等键；同连接 IMMEDIATE 事务核对当前来源、CAS更新配置与catalog_receipts。同键同内容返回原提交revision及另行读取的当前视图；异内容冲突。窄status校验workspace/project/current，通用Catalog status拒绝此类回执，避免旧标签泄露或旧回执倒退新配置。未知回执先用原project/view/key核对；重启不自动重发。

先行合成文件DB Spike已验证原连接配置/回执原子回滚、双连接CAS、提交后丢回执原键恢复和关闭重开；原始证据在本轮仓外dev1910-a目录，独立技术复核和GUI/律师接收另列。新增迁移只增不改旧SQL/hash；候选编号需主控串行接入时重核。当前仅合成测试库已迁移，未接触用户库；仓外应用前可撤回本轮准确增量。迁移桥接对未知较新DDL/历史继续fail-closed，因此已升级库不能简单反向整份补丁运行旧码。未来功能回退必须保留已发布新增迁移、manifest、marker和schema兼容层及配置/回执数据，只撤功能接线；受控备份恢复另由原Owner明确执行，不能擅自删表或降库。后续撤销只提交显示字段的新CAS动作，不回滚业务对象。此决定不等于完整六图、AI、固定交付或律师验收完成。
