# ADR-017｜任务分页读取缓存试点

[DEV-1800](https://linear.app/logixy-ai/issue/DEV-1800) · 用户已批准限定任务列表读取。

- Renderer 使用精确版本 `@tanstack/react-query@5.107.1`，依赖 `@tanstack/query-core@5.107.1`。两包为 MIT，React 19 符合 peer 范围。通过 npm 依赖引入，不复制源码。来源为 [TanStack Query](https://github.com/TanStack/query)，许可清单由现有脚本生成。
- 每个工作台实例只有一个 QueryClient。键含完整 TaskListQuery，缓存只驻内存，60 秒内可复用。只通过原 typed IPC 读取，不依赖网络在线状态，无自动重试。筛选、选择、滚动和编辑状态仍由页面持有。
- SQLite 是任务权威。现有保存、幂等回执及工作区授权继续走原入口。刷新入口先取消过期的缓存读取，再标记任务分页失效。取消不代表中止宿主 IPC。全量任务快照继续服务原消费者。
- 当前应用按单本地工作区运行。跨工作区或宿主外部写入接入时，重新审查键与变更通知。其他列表的保存继续由原业务流程管理。
- 回退为撤销提交，移除读取缓存和新增依赖；没有数据迁移。


## DEV-1801 普通目录共享

文档、知识库与财务项目选择器共用普通 `catalog.list` 内存缓存。项目专业目录、账本、正文和材料由原入口负责。普通目录保存结果不写入缓存，已确认回执触发重新读取；其他影响目录的已确认写入沿现有刷新入口标记目录过期。页面再次打开时重读。

文档组织、归档和恢复沿原键与版本执行。成功提交但目录读回失败时保留读回守卫，手动刷新只读取目录。财务账本的原回执读回与冲回证据检查不经 Query。
