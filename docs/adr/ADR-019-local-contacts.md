# ADR-019｜本机联系人与项目关联

DEV-1806 首版。联系人由同一 SQLite 连接里的独立适配器管理，通过受控 Application 和工作区 IPC 读写。采用联系人、关联表和原提交回执，同事务保存。跨项目可引用同一联系人，关联不推定客户或付款方身份。未采用项目内重复文本、浏览器本地存储和可自动合并的姓名键。

迁移 0016 只新增表。客户端提交带期望版本、记录 ID 和原提交身份。确认失败重用原提交，内容改变必须取得新身份。工作区和项目 ID 在事务内核对。联系人信息不进入 Agent、日志或网络。

回退 UI 与宿主接线时保留 SQLite 表和已提交数据。引入客户角色、共享、合并或出站功能时重新审查权限、审计和数据恢复。
