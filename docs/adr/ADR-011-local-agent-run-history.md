# ADR-011｜本地Run记录与中断恢复

2026-11-05；用户授权五页数据库接线后连续推进；主责任DEV-1653，基线605ad99。只持久化既有Run的本次确认输入、输出、模型、scope、时间、序号、状态及已知用量；不把Run保存冒充1699纯人工消息/材料/成果关联整卡，也不扩大AI上下文。

复用同一SQLite连接与追加迁移。运行记录唯一持久化Owner是本地agent_runs，Application内Map只作当前进程投影；assistant-ui不持久化第二套会话。凭据从不进入记录，错误不反射Provider响应。Run必须先INSERT-only原子登记成功再发起Provider；同ID已存在只核对旧记录，检查点仅更新已登记且输入身份一致的更高序号。同一userData工作区通过Electron单实例锁阻止第二活进程，只有取得工作区锁后的启动恢复可将running改为interrupted；纯读取不改变状态。保存失败停止并保留明确错误，不重试网络。

流式输出以累计文本投影，按文本事件以500ms间隔节流保存检查点（不是最后增量最多500ms的持久化保证）并在终态强制保存。进程强退时最多丢失尚未检查点的增量，重开保留已落盘部分，running转换interrupted且用量未知；绝不自动续跑或创建新收费请求。同run_id重放核对已有输入/scope/model，不能再派发；历史每次独立，不自动成为下一次模型输入。

跨进程历史属于当前本地workspace；当前进程的新Run仍保留窗口所有权，其他窗口不读取正在执行的输入。重开历史进入只读投影，原scope经当前Task存在校验；Project/文档/知识库的AI始终使用关联Task ID，不用Project ID冒充任务。暂不引入多用户共享或云端线程。

验证：真实SQLite重开、running中断/未知用量、终态/取消/迟到隔离、登记失败不派发、同ID/异scope/异model拒绝；真实Electron合成生成→强退在途Run→重开查看历史且零新请求。模型联网真实Key仍独立NOT_RUN。回退应用代码不删除Run表或历史，旧版忽略新表。
