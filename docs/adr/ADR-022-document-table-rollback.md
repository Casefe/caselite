# ADR-022 文档表格的读取基线与写入回退

- Issue [DEV-1812](https://linear.app/logixy-ai/issue/DEV-1812)
- 起点 `8b8dffe`，适用现行 02、03、05、06
- Owner 文档正文与本地存储

任务成果继续以 SQLite 中的 Yjs 修订为唯一正文。表格沿用 Tiptap TableKit 3.32.3 与已有协作 schema。读取支持表格、行、表头及单元格，宿主校验矩形覆盖、跨度、列宽和结构上限。列宽 0 表示 ProseMirror 插列后尚未设宽。项目说明、任务内容、评论沿各自已有写入格式。

先保留独立的读取提交，再接入表格写入。回退写入提交后，预览及成果正文仍渲染已保存的表格。含表格的成果进入只读，宿主事务拒绝替换该修订，也拒绝新增含表格的修订。无表格成果继续正常保存。回退目标是读取提交，回退早于该提交的安装包会拒绝读取表格。数据库结构和现有正文二进制沿用原格式。

验收使用同一合成工作区从写入版保存并退出，再用读取版重开，核对相同正文与修订。对只读版直接提交替换请求应失败。两阶段检查均保留原件、权限、预期版本和幂等规则。
