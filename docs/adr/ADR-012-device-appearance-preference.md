# ADR-012｜设备外观偏好

- 状态：提议（本地原型已实现，独立复核待完成）
- 日期：2026-11-06
- Linear Issue：[DEV-1746](https://linear.app/logixy-ai/issue/DEV-1746)
- 影响模块：桌面设置、Preload/IPC、Application 与本机外观配置适配器
- 责任与人工确认：用户指定浅色和深色；视觉接收及独立复核待完成
- 代码位置：`packages/contracts/src/appearance.ts`、`packages/application/src/appearance-application.ts`、`apps/desktop/src/main/adapters/appearance-preferences.ts`

## 背景与不变量

主题仅是设备级界面偏好，不是任务、正文或模型输入。Renderer 不直接读取本地文件；固定 IPC 必须校验可信窗口、请求与响应。未知版本或损坏的设置文件不得被自动覆盖，读取或保存失败不得显示为成功；人工工作与模型权限不受主题影响。

## 候选与实现

| 方案                                                   | 优势                             | 限制                                         |
| ------------------------------------------------------ | -------------------------------- | -------------------------------------------- |
| 设备私有版本化配置文件，经 Application 和固定 IPC 访问 | 不改业务数据库；可校验并单独回退 | 需单独纳入未来设备设置的备份、迁移和恢复策略 |
| Renderer 本地存储                                      | 接线少                           | 与本仓库受控存储边界不符                     |
| 业务数据库新增表或迁移                                 | 可并入统一备份                   | 仅为一个外观偏好增加业务 Schema 和迁移成本   |

当前原型采用第一种：主进程持有 `appearance-preferences.json`，版本 1 仅存储 `light`／`dark`；先校验旧文件，再写入独立临时文件、同步文件内容并原子替换。按 [DEV-1841](https://linear.app/logixy-ai/issue/DEV-1841)，仅未找到配置时默认深色，不因缺省值变更改写用户已保存的浅色或深色；无效、未知版本或 I/O 失败返回可见错误。确认结果以重新读取为准。它不承诺设备断电时目录项必然持久，也不存储案件、密钥或用户输入。

## 验证、回退与重新评估

通过应用层非法输入及写入失败测试、文件跨实例读取和损坏保护测试，并用隔离 Electron 验证切换及重启读回；具体构建和命令以交付证据为准。旧版忽略此配置文件，回退应用无需删除用户数据。未来加入其他设备偏好、备份迁移、跨设备同步或配置格式变更时，须重新评估唯一 Owner、兼容和恢复路径；本原型不启用同步。
