# ADR-012｜设备外观偏好

- 状态：提议（本地原型已实现，独立复核待完成）
- 日期：2026-11-06
- Linear Issue：[DEV-1746](https://linear.app/logixy-ai/issue/DEV-1746)
- 影响模块：桌面设置、Preload/IPC、Application 与本机外观配置适配器
- 责任与人工确认：用户指定浅色和深色；视觉接收及独立复核待完成
- 代码位置：`packages/contracts/src/appearance.ts`、`packages/application/src/appearance-application.ts`、`apps/desktop/src/main/adapters/appearance-preferences.ts`

## 背景与不变量

主题仅是设备级界面偏好，不是任务、正文或模型输入。Renderer 不直接读取本地文件；固定 IPC 必须校验可信窗口、请求与响应。未知版本或损坏的设置文件不得被自动覆盖，读取或保存失败不得显示为成功；人工工作与模型权限不受主题影响。

## 候选与实现

| 方案                                                   | 优势                             | 限制                                         |
| ------------------------------------------------------ | -------------------------------- | -------------------------------------------- |
| 设备私有版本化配置文件，经 Application 和固定 IPC 访问 | 不改业务数据库；可校验并单独回退 | 需单独纳入未来设备设置的备份、迁移和恢复策略 |
| Renderer 本地存储                                      | 接线少                           | 与本仓库受控存储边界不符                     |
| 业务数据库新增表或迁移                                 | 可并入统一备份                   | 仅为一个外观偏好增加业务 Schema 和迁移成本   |

当前原型采用第一种：主进程持有 `appearance-preferences.json`，版本 1 仅存储 `light`／`dark`；先校验旧文件，再写入独立临时文件、同步文件内容并原子替换。按 [DEV-1841](https://linear.app/logixy-ai/issue/DEV-1841)，仅未找到配置时默认深色，不因缺省值变更改写用户已保存的浅色或深色；无效、未知版本或 I/O 失败返回可见错误。确认结果以重新读取为准。它不承诺设备断电时目录项必然持久，也不存储案件、密钥或用户输入。

## 验证、回退与重新评估

通过应用层非法输入及写入失败测试、文件跨实例读取和损坏保护测试，并用隔离 Electron 验证切换及重启读回；具体构建和命令以交付证据为准。旧版忽略此配置文件，回退应用无需删除用户数据。未来加入其他设备偏好、备份迁移、跨设备同步或配置格式变更时，须重新评估唯一 Owner、兼容和恢复路径；本原型不启用同步。

## DEV-1652｜对话主题操作的最小准入｜2026-11-11

用户明确批准先实现主题闭环，其余设置不开放。仅首页无附件、无页面引用的明确主题指令可由宿主签发一次性授权；否定、咨询、假设、引用和混合指令不授权。有限表达采用全句校验，不能识别时回到普通无工具对话，不声称支持任意自然语言。Pi 只在本次授权运行公开一个主题提案工具；模型参数再次校验且必须等于用户批准的目标。提案在原 Application 执行，不允许 Pi 直接访问文件；普通材料运行仍禁用工具。单次 Provider 请求，提案处理、结果卡、核对和撤销均本地完成，不为工具结果自动续费。

主题文件仍为原 version 1 格式，唯一 Owner 不变。原 Appearance Application 为所有本进程主题 set 维护会话内单调修订，写入尝试也使旧授权/撤销失效，防止手动切换改走再改回后覆盖新选择。宿主生成操作身份并绑定窗口生命周期；记录只保留目标值、原值及结果，原 Run 关联其最小投影。结果未知只核对原操作，不重新执行；当前值相同不能证明本次提交归属。保存和 DOM/原生窗口应用分开确认。

授权与撤销仅在当前应用/窗口会话有效。退出或文档级导航撤销令牌；SPA页面切换仍属于同一窗口会话，不承诺取消已授权的设备主题操作。重启只读原偏好，不自动续跑；旧 Run 的历史记录不能复活权限。撤销经原Agent Application校验Run/窗口后进入外观Owner，更新同一Run的结果/sequence并沿原history保存；记录落盘失败与实际主题效果分别显示，只读核对可恢复记录而不重放效果。旧外观IPC仍只支持原read/set/applied，不能旁路Run历史执行撤销。

撤销须核对原操作身份、窗口、当前修订和目标值，仅恢复本次主题。后续人工选择（包括改走再改回）使旧卡明确标记为已被取代，不再显示等待同步。进程外直接编辑配置文件不是受支持的并发写入接口；发现读取值变化即失效，无法承诺检测两次读取之间的外部 ABA。若将来需要跨进程写入或跨重启撤销，必须重新设计持久修订和恢复协议，本切片不预建日志库。

验证包含真实 Pi 配合合成 Provider、Application 的拒绝/重复/ABA/未知回执、真实文件与 Electron UI/重开；真实 Provider 和律师接收分别记录。回退撤销本切片代码而保留偏好文件及历史，不修改凭据、旧费用账本或其他工作区设置。
