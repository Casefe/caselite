# ADR-026：工作区本地个人资料与显示偏好

状态：DEV-1821 已通过工程测试和独立复核；原生界面接收受工具阻塞。

## 决定

名称、可选邮箱、预设头像与文档字数显示存入当前工作区既有 SQLite。它们不是云端身份、团队成员或任务负责人，不注册账户，不发送邮件。主题继续由原 Appearance Owner 管理；本次不迁移主题，不建立第二份个人资料真源。

Renderer 通过严格 Schema 的 Preload/IPC 调用 Application，再调用工作区绑定的 Store。Renderer 不能指定工作区或任意路径。值、递增版本、请求摘要与原键回执在同一 SQLite immediate 事务内提交。读取默认值不写库；跨窗口陈旧版本拒绝覆盖。

结果未知时保留原输入和原提交，只能核对原键。确认没有回执后才允许重试原提交；确认保存后的刷新失败仅重读。原键返回旧回执时，再读当前值，避免用旧确认覆盖新显示。提交未改变的值被界面阻止。

文档字数是现有正文的显示投影，按非空白 Unicode 码点计数，包含标点。不开启时不扫描正文；不写 Yjs、正文修订或 Activity。项目说明、任务说明和评论没有字数显示。

## 迁移与回退

0019 仅新增 `local_preferences` 与 `local_preference_receipts`，不修改已有表、材料、正文、交付快照或凭据。升级前对独立验收库做一致性备份，验证 19 → 20 迁移以及保存重开。撤销界面入口时保留两表及读取能力，不删除用户资料；旧应用不得反向迁移数据库。

## 验证与边界

验证严格入参、可信发送端、同键重放、摘要冲突、版本冲突、事务回滚、工作区隔离、重开、未知结果恢复和刷新失败。原生窗口不可控时明确列为 BLOCKED，不用组件测试代替用户接收。头像上传、云身份、通知、邀请、公开分享和数据库搬迁均不属于本卡。

2026-11-08：quick 通过（278 单元、89 合同），集成 146 项通过。独立复核发现的初次读失败后重读默认值覆盖问题已修复并补负例；4 项控制器恢复测试复核通过。19→20 迁移保留旧表的测试通过。原生点击返回 `noWindowsAvailable`，真实表单保存/重开与视觉验收仍 BLOCKED；不得据此标记业务已完成。

DEV-1822 只读增量：Main 将当前 taskRoot 的数据库文件和受管导出目录绑定为 Application 的只读元数据，只随 read 成功响应返回；set/status 不附加目录，目录不进入 SQLite 可编辑值或历史回执。Renderer 不能在请求中指定路径、操作目录或迁移数据。本机设置页面显示当前路径不等于授予文件系统能力。没有新通道、迁移或依赖；回退只撤销此显示和响应元数据。

## DEV-1830 日历列宽消费者

可选 `calendar_layout`（日期栏220—460px、属性栏280—560px）保存在同一偏好JSON，沿既有set/status、工作区绑定、预期版本、原键与SQLite事务，不新增表、迁移、IPC通道或浏览器存储。省略字段的旧请求不改摘要，并保留现有布局；旧回执不注入默认字段。日期栏缺省为原230px的7/6，右栏缺省340px；仅显示时按窗口约束clamp，不把缩窗结果覆盖保存值。

Renderer继续使用原LocalPreferencesProvider；布局提交从已保存个人资料构造，不自动提交设置页草稿。确认或重读后只保留真正改动的个人草稿字段，其余字段与布局从最新保存值刷新，不能凭空制造陈旧草稿。未知结果由长寿命Provider保留原请求，离开日历不换键或自动重发；状态核对与失败刷新沿原控制器。拖动结束或键盘释放才提交，取消只撤销显示预览；改变列宽不卸载Task/AI子树。UI回退保留新字段读取和旧请求省略保留逻辑，不能直接退到不接受该字段的旧Schema。

## DEV-1859 右侧组合统计卡片消费者

任务、项目、财务的统计卡片显示配置使用可选 `statistics_cards`，出现时要求 tasks/projects/finance/contacts 四个模块的完整严格对象，各含 `enabled` 和 top/middle/bottom 位置。联系人按本期批准范围暂不启用；消费者能力限制优先于恢复配置。读取缺省解释为任务、项目、财务开启且位于右上，联系人关闭，不因读取默认值落盘。

复用同一 LocalPreferencesProvider、Preload/IPC、Application、SQLite JSON、预期版本、原键摘要和 immediate 事务；不新增表、迁移、通道、浏览器存储或统计真源。摘要继续基于原请求计算，省略字段的旧请求在摘要计算后保留现有配置，旧回执保持原形状。日历列宽提交继续从已保存资料构造，确认/刷新/冲突重读时保留真正改动的统计草稿。整体配置更新须保留其他模块设置，未知结果核对原键。

共享 StatisticsCard 只显示消费者传入的格式化值、未知状态和视觉比例；统计范围和计算归原 TaskListSummary、ProjectMetrics、FinanceView。财务总收入按用户确认的有效收费合同总额；净开票、有效客户回款和待收款分别对比总额，不解释为可相加分区。InspectorCards 在同一属性滚动区内按稳定 ID 组合卡片，右上位于属性前、右中位于属性后、右下位于属性区末尾且在 AI 上方；位置切换不重挂载属性/AI。短窗口通过属性区滚动访问卡片。

回退拆分兼容支持与 UI 消费。撤销 UI 时保留新字段 Schema 与旧请求保留逻辑，不删除用户配置，不直接运行不接受新字段的旧包。需要完整版本回退时另行核对兼容迁移。工程与原生验收结果以本轮真实证据为准，本段决定不代表功能已验收。

## DEV-1860 收藏快捷引用消费者

收藏导航使用可选 `favorite_navigation` 保存一级文件夹、带类型的 Task/Project 引用及 Document 的文件夹位置。仅保存 ID 与位置，不保存标题、正文、权限或第二份对象。Document 是否收藏继续以 `documents.favorite` 为唯一真值，经原 Catalog `organize_document` 更新；位置记录本身不产生文档收藏。归类不移动任务归属、原件或正文，缺失或已归档对象不展示为可打开的快捷入口，保留引用以支持原对象恢复。

复用同一工作区 LocalPreferencesProvider、严格 Schema、既有 IPC/Application 和 SQLite JSON 事务，不新增表、迁移或通道。收藏提交从已保存资料构造，确认、原键恢复及只读刷新时保留个人设置和统计卡尚未保存的草稿。旧客户端省略新字段时在原请求摘要计算后保留已有收藏；旧摘要与回执不改写。未知结果先核对原键，ACK 后读失败只重读。UI 回退保留新字段读取和省略保留逻辑，不删除用户收藏或运行拒绝新字段的旧 Schema。

App 负责组合项目星标渲染槽，项目功能不依赖收藏功能实现；侧栏从当前目录解析标题和有效对象。无嵌套、全局排序或多用户同步承诺。具体工程验证和律师接收仍以本轮证据为准。
