# ADR-026：工作区本地个人资料与显示偏好

状态：DEV-1821 已通过工程测试和独立复核；原生界面接收受工具阻塞。

## 决定

名称、可选邮箱、预设头像与文档字数显示存入当前工作区既有 SQLite。它们不是云端身份、团队成员或任务负责人，不注册账户，不发送邮件。主题继续由原 Appearance Owner 管理；本次不迁移主题，不建立第二份个人资料真源。

Renderer 通过严格 Schema 的 Preload/IPC 调用 Application，再调用工作区绑定的 Store。Renderer 不能指定工作区或任意路径。值、递增版本、请求摘要与原键回执在同一 SQLite immediate 事务内提交。读取默认值不写库；跨窗口陈旧版本拒绝覆盖。

结果未知时保留原输入和原提交，只能核对原键。确认没有回执后才允许重试原提交；确认保存后的刷新失败仅重读。原键返回旧回执时，再读当前值，避免用旧确认覆盖新显示。提交未改变的值被界面阻止。

文档字数是现有正文的显示投影，按非空白 Unicode 码点计数，包含标点。不开启时不扫描正文；不写 Yjs、正文修订或 Activity。项目说明、任务说明和评论没有字数显示。

## 迁移与回退

0019 仅新增 `local_preferences` 与 `local_preference_receipts`，不修改已有表、材料、正文、交付快照或凭据。升级前对独立验收库做一致性备份，验证 19 → 20 迁移以及保存重开。撤销界面入口时保留两表及读取能力，不删除用户资料；旧应用不得反向迁移数据库。

## 验证与边界

验证严格入参、可信发送端、同键重放、摘要冲突、版本冲突、事务回滚、工作区隔离、重开、未知结果恢复和刷新失败。原生窗口不可控时明确列为 BLOCKED，不用组件测试代替用户接收。头像上传、云身份、通知、邀请、公开分享和数据库搬迁均不属于本卡。

## DEV-1830 日历列宽消费者

可选 `calendar_layout`（日期栏220—460px、属性栏280—560px）保存在同一偏好JSON，沿既有set/status、工作区绑定、预期版本、原键与SQLite事务，不新增表、迁移、IPC通道或浏览器存储。省略字段的旧请求不改摘要，并保留现有布局；旧回执不注入默认字段。日期栏缺省为原230px的7/6，右栏缺省340px；仅显示时按窗口约束clamp，不把缩窗结果覆盖保存值。

Renderer继续使用原LocalPreferencesProvider；布局提交从已保存个人资料构造，不自动提交设置页草稿。确认或重读后只保留真正改动的个人草稿字段，其余字段与布局从最新保存值刷新，不能凭空制造陈旧草稿。未知结果由长寿命Provider保留原请求，离开日历不换键或自动重发；状态核对与失败刷新沿原控制器。拖动结束或键盘释放才提交，取消只撤销显示预览；改变列宽不卸载Task/AI子树。UI回退保留新字段读取和旧请求省略保留逻辑，不能直接退到不接受该字段的旧Schema。
