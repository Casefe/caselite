# ADR-039｜独立文档复用现有 Document 与 Yjs 正文

- 状态：已实现候选；隔离 R2 已通过，桌面与律师验收未运行
- 日期：2026-11-15
- Issue：DEV-1934
- 批准：用户在四栏 UI 改版中明确选择“一并补齐真实文档创建”。

## 问题与不变量

原 `documents.task_id` 非空且唯一，文档名称与时间来自 Task，正文读写入口也绑定 Task。独立文档不得隐含创建任务，不建立第二正文表或编辑内核。沿用现行02/03、ADR-010、ADR-013 的 Document/personal 方向；本次不实现每日笔记、日期索引或新的同步服务。

同一 SQLite 连接维护 Document 元数据、`body_revisions` 的完整 Yjs 修订、活动及幂等回执。任务成果继续一 Task 一 Document；Task 的标题仍由 `task_items` 唯一持有。个人文档没有 Task 或项目绑定，其名称、工作区和更新时间仅属于该 Document。

## 决定与兼容

追加 `0035_personal_documents.sql`，不修改历史 SQL。现有锁定 `better-sqlite3` 实际加载 SQLite 3.53.4，支持原生 `ALTER TABLE ... ALTER task_id DROP NOT NULL`。保留父表、Task UNIQUE、body UNIQUE 及现有快照外键，增加仅个人分支持有的工作区、标题和时间列，最后增加默认 `task` 的 owner 与互斥 CHECK。Task 必须绑定 Task 且个人字段为空；personal 必须没有 Task 且个人元数据完整。

没有重建或删除文档父表，不修改迁移执行器，不关闭外键或清除延期外键计数。初次父表替换候选在完整旧数据上发生提交时外键失败，已回滚并保留证据；不能用空表试验放行。此次选择原生 ALTER，避免该失败路径。

通过既有 Catalog 通道增加 `create_document`、`read_document`、`save_document_body`，不增加 Preload 顶层 API、权限或运行时。旧 Task 回执缺少 owner/schema 字段时仅兼容原 Task 分支；personal 必须显式标明 owner 且 `task_id`、`matter_id` 为空。既有请求内容与幂等摘要不改写。

创建时在存储 Owner 内生成一个合法空段落的 Yjs 状态，Document、初始修订1、活动和回执同事务提交。个人正文保存验证工作区、Document/body 身份、期望修订、格式单调和归档状态；新修订、时间、活动及回执同成败。元数据版本与正文修订分别维护，正文保存不覆盖标签或分类。

新建默认 `in_library=false`；用户仍可显式经既有组织命令把同一文档加入知识库，不创建副本或自动定稿。文档页 AI 只复用同工作区的 `document:<ID>` 与已保存名称/正文读取，不增加自动发送或模型调用。Task 专属选段写回、固定交付快照和导出没有扩展到 personal；界面须明确禁用原因，不伪造 Task 或快照。活动持久化沿 Catalog，现有按 Task/Project 的活动列表不因本次新增全局个人文档活动视图。

## 验证与证据边界

仓外合成 R2 使用逐字节相同的真实迁移执行器与候选 manifest，完整旧链35条升级到36条。13项场景覆盖63张既有表的旧行投影及 Blob 哈希、快照/导出及意图/材料源和派生/活动保全、空库、每条 DDL 与迁移记账前故障回滚、重开、一致 SQLite 备份恢复、支持的 A/B 双历史、旧迁移程序拒绝新历史且不写库。新列在旧 Task 上仅为确定的默认值。当前实际 Schema 没有独立 Anchor 表，未虚构 Anchor 迁移验证。

领域合同/集成测试另覆盖合法空 Yjs、无隐藏 Task、同键重试与异内容冲突、原键状态查询、跨工作区拒绝、旧修订/错误 body/非法 Yjs/格式降级/归档拒绝、创建和保存阶段故障原子回滚、本库合法 Task 父行的 owner CHECK，以及升级后原 Task 创建/保存/读取/状态接口。既有迁移并发保全测试保留所有旧列逐项相等，并显式断言新增默认列。

共享编辑器与 UI 接线须按显式 Document Owner 实现，不给个人文档伪造 Task。保存 ACK 必须绑定原 receipt、target/document/body、期望下一修订和格式，错配/迟到响应不能清除草稿；结果未知查询同一键，明确不存在后才重发冻结请求。创建成功后以稳定 Document ID 刷新目录并重读，原回执不是最新目录真源。

真实 Electron 所加载 SQLite 版本、打包迁移/重开、物理中文输入法、磁盘或进程异常与律师体验未运行。Node SQLite 与 R2 通过不替代这些验收，也不授权自动启动软件。

## 回退与重新评估

修改前保全精确源码前像；测试仅用本任务创建的合成库。迁移失败应撤回本次 DDL、数据及迁移记录，旧库仍可重开。升级后的新历史会被旧迁移程序拒绝，不能把旧二进制换回后继续写新库。有个人文档数据后优先前进修复，或在独立目录核验并恢复一致备份；禁止删除个人文档、回填假 Task 或用旧备份覆盖用户后来修改来证明回退。

新增个人文档项目归属、复制、固定交付、导出、专业写回、同步或改变支持的 SQLite 版本时重新审查该 Owner、兼容和恢复边界。本 ADR 不是这些能力已完成的证明。
