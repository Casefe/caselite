# ADR-010｜五页数据接线的本地目录增量

2026-11-05；用户授权检查五页并一并开发Schema相关卡；基线f7f591e。主数据迁移入口DEV-1590，文档生命周期1626、库组织1630、项目1596/1597及归组1700独立验收，部分范围不关闭整卡。

复用同一个SQLite连接、Drizzle增量迁移、Application与类型化Preload。新增目录查询/命令入口仅承担项目和文档元数据，不替换既有Task/正文接口，不将工程CreateMatter内存Spike当作产品持久化。Document仍一Task一成果；独立资料文档/复制/正式定稿另按原卡推进。

Document增量元数据保存在既有documents表：元数据版本、归档、分类、标签、收藏、是否在个人知识库显示。知识库是现有Document的显式组织视图，条目仍指向可编辑原文，既不自动确认定稿也不冒充固定版本知识沉淀。Task列表不因Document归档而消失；归档正文只读、恢复保留原ID/body/修订。

Matter独立身份/名称/普通状态/版本/归档及说明body绑定；说明复用body_revisions与Yjs校验，独立bodyId和bodyRevision。元数据和正文同时更新时同事务提交，不另存可编辑HTML或JSON。Task与Matter关联独立关系表；目标必须同workspace且未归档，Task ID/Document/body/历史不变。归组更新Task version；现有旧Task DTO/回执省略matter时仍兼容null。

目录写入、幂等回执和活动同事务；以明确expectedVersion拒绝旧对象覆盖。同键异内容拒绝，未知回执保留同一请求核对。归档只改变对象生命周期，不级联删除任务、正文或历史。新DDL只增迁移，不改旧迁移。

本次先验证空库与旧库迁移、真实SQLite事务故障、幂等、跨workspace拒绝、正文独立与归档恢复、原任务/正文不变、打包创建后重启读回。Agent输入仍仅当前确认文字；对话/WorkRun持久化由1699/1653单独接线，不因目录接入扩大模型上下文。文件导入/来源链/正式定稿复制不在目录元数据实现内。

回退应用提交并恢复升级前隔离备份；不得删除用户数据或就地回退Schema。新增表/列保留时旧版忽略它们；旧版无归档保护，不用于编辑新版已归档文档。独立复核必需。

## DEV-1700｜独立任务创建项目的原子提交（2026-11-06）

在既有catalog通道增量加入promote_task命令，输入原Task ID、expected_version、项目名称及原有幂等字段。仅未归组、同工作区且版本匹配的Task可执行；已归组或旧版本明确拒绝，不另建Project。创建Matter、关联原Task、更新Task版本、必要活动及回执在同一SQLite事务中完成；任何一步失败全部回滚，同键重试返回原结果。

不新增表、正文格式、Runtime或权限模型，不改Task/Document/body/来源/Run/旧快照身份，也不扩大AI上下文。界面从原任务详情进入，结果未知保留原请求核对；正式接受仍由用户明确保存。回退此命令的应用代码，不删除已创建项目或原任务；数据继续兼容原创建/归组接口。以事务中断、重复/冲突、跨工作区及真实Electron重开验证，独立复核结果另留本卡证据。
# DEV-1608 只读活动投影｜2026-11-06

复用 catalog IPC 与原连接查询 task_activity/catalog_activity，不增加迁移或写事件入口。按明确 Task 或 Project 范围核验同workspace，20项分页；项目展示当前归属任务的历史，非当时成员快照。任务侧保留其归组事件，项目侧用对应目录事件避免重复展示同一次归组。回跳再次核范围/目标/归档，只能打开当前对象，不声称恢复事件时修订。

现有表未保存操作者和对象修订，查询明确返回null，UI显示“未记录”；不按时间匹配回执、不推算身份/版本。材料登记、定稿、快照及导出没有可消费事件，显示未接入；补全可信事件字段及写入留原1591及各动作Owner，不能在1608倒造历史。只读查询失败保留列表并允许重读，目标失效保留历史。无正文/原件/运行日志进入活动内容。
