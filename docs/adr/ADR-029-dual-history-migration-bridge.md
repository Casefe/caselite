# ADR-029｜双历史迁移接合（DEV-1826）

状态：提议；以本卡实际 Spike、定向测试及独立复核决定放行。

基线：A 为 7cf73e0（0017 快照、0018 导出、0019 偏好、0020 日历）；B 为 d2df83e（0017 订阅、0018 健康、0019 里程碑）；共同历史截至 0016。依据为现行02 TASK-CALENDAR（2026-11-09T00:38:13.754Z）和 DEV-1826。

## 问题与不变量

已安装 Drizzle 0.45.4 的 SQLiteSyncDialect 在 BEGIN 前读取 max(created_at)，只执行更晚迁移。单纯排序合并 journal 会让 A 历史库跳过 B 的三份 DDL，即使 integrity_check=ok。不得改已应用 SQL/tag/when、覆盖迁移记录、重建业务表、清库或改正文/原件/回执。

## 采用候选

仅带 meta/dual-history-1826.json 的完整冻结目录启用窄 TypeScript pre-migrate bridge。编译内 manifest 冻结 24 份 SQL 的 tag/when/hash；marker、完整 journal 和 SQL 字节逐项匹配。缺 marker 的目录若 journal 同时出现 A/B 分叉 tag 则拒绝，不按固定长度判断；真正单支旧夹具保持自身迁移范围。复制当前目录并裁剪为旧夹具时必须明确移除 marker，不能带着完整目录身份运行半套迁移。

桥接在 SQLite IMMEDIATE 事务内重新读取全部 (hash,created_at) 和 schema；已知前缀为共同历史、各自分支前缀及 B 完整＋A 前缀。重复/未知记录、前缀空洞、A 与部分 B 混合、记录缺而结构存在、记录有而结构缺失及异形全部拒绝。用同一 SQLite 引擎在内存重放实际记录顺序，核对 sqlite_schema 的表、约束、索引、外键和触发器；不读取业务行，不增加持久数据库。

只对 A 已越过 B 且 B 完全缺失的库补 B 三份原 SQL 和原 hash/when。全部补写同事务，失败回滚。之后仍调用原 Drizzle migrate 完成常规后续迁移。原件路径、正文二进制和旧业务值不被桥接读写。

0020_snapshot.json 仅接合当前完整 schema 的生成元数据（沿用其 id/prevId），以反映 B 的既有列/表；所有 A/B 已应用 SQL、tag 和 when 仍逐字节保留。两份原始 journal 作为测试夹具保留，升级测试不再用合并目录的位置冒充原 A 历史。

## 并发、失败和回退边界

Drizzle 内部直接 BEGIN，不支持把 migrate 嵌入外层 IMMEDIATE。桥接事务结束与普通迁移开始间存在竞争窗口；本方案不修改依赖、不实现第二迁移器，也不重试未知异常。竞争连接可安全失败，重开后重新验证。需要证明：双开不会重复补写或留下半形状；故障后重开收敛；SQLite 锁错误如实返回，不假称两次同时启动必然成功。生产 Electron 原有单实例约束保留。

桥接完成后常规迁移失败时，已提交的 B 补齐仍是已知可重开状态；不承诺两段事务共同回滚。桥接本身失败须证明三份 DDL/记录全部撤回。旧二进制回退仅保证它原有的读取能力，不能保证理解新增日历/订阅操作或回执。代码回退使用本卡小提交；升级副本可恢复到升级前一致性备份，禁止为回退删除用户后来写入的库。

## 放弃方案与验证

放弃重新编号/修改已应用 SQL、只拼 journal、IF NOT EXISTS 掩盖结构、按当前表推断迁移成功和清空重建。改变数据库所有权、通用迁移平台及同步协议均不在范围。

定向测试需从原 A/B SQL 逐份创建真实 SQLite 历史库，覆盖共同前缀、A/B 各中间版本、A 日历、fresh、重复打开、未知/半迁移拒绝、事务故障及并发；对旧行、Yjs、原件、历史/回执/快照/提醒做字节或值保全。随后同 SHA quick、review、security、integration、full/原生包，独立高风险复核和主控 GUI 验收分别留证。真实 Provider 自动调用为 0；不接 EventKit/Google，不替换固定验收库。

## 后续获准迁移的维护

后续 Issue 如需新增迁移，单写入者只在冻结 manifest 末尾追加经批准的新 SQL/tag/when/hash，并更新 marker 摘要与完整 journal；所有已发布项保持原字节/值，禁止重算旧项来接受未知库。若新迁移改变已存在表的结构，schema 重放继续按真实已应用记录顺序核对。新增项不是旧库已应用记录；旧 24 项完整库必须作为升级夹具证明只追加新 DDL、数据/回执保全及重复打开，未知/缺 marker 仍拒绝。原 A/B 各前缀和 24 项回归必须保留；追加迁移改变识别条件时更新 ADR 并独立复核。当前不预建 DEV-1825 字段。
