# ADR-032｜页面范围 AI 与文件式引用

DEV-1781，2026-11-09 用户追加授权：默认仅紧凑输入、页面独立历史、整页/选区引用卡，测试后同步主目录并合并 GitHub。原布局、Agent Application、SQLite Run 与 Yjs 正文 Owner 保持。

项目使用现有 `project:<UUID>`，任务内容使用 Task UUID，文档及其审阅使用现有 `document:<UUID>`；文档目录不能再借 Task scope 读取聊天。各对象页面的不同导航入口共用该对象范围，不复制历史、不将旧任务记录迁入文档。历史只用于本页展示，不拼入模型输入。

`preview_page` 是本机只读动作。通过 Application 调用唯一存储连接的页面 Port，读取当前工作区该对象的已保存内容：项目概述及其属性、任务内容及其属性、文档正文及标题。子任务、讨论、关联对象正文、历史、附件和秘密不自动加入。Yjs 仅派生纯文本，不生成第二份可编辑正文。文档表格使用既有已验证 schema 的文字投影。

选区优先；Renderer 只提交有界选区文字，Application 必须验证它属于该页面当前已保存内容。归一化空白用于校验跨段/表格文字，不接受任意外部文本或退化成全文。可支持单段审阅位置时仍沿原 ReviewRange/preview_review，保留人工确认新修订；其他选区和整页为聊天，不开放自动写回。

引用正文只在受控应用进程内保存；每窗口每页面仅最新引用，每窗口最多32份。Renderer 只得到随机引用ID、标题、类型和字数，显示为TXT卡片，不将正文填入输入框或消息。点击发送才绑定ID；跨窗口/范围、归档、版本或文字变化、准备期间变化均拒绝。单轮页面、问题和附件总文本不超过32000字符；超限提示缩小引用，不静默截断。

AgentRun加性记录 `page_context_id`、`page_reference` 元数据，无新表/迁移。历史登记/检查点固定这些输入身份，旧Run缺失字段继续读取；同Run重放不派发，未知回执保留原ID核对，明确拒绝后解除旧发送状态。进程重启不恢复未发送引用正文；已登记Run只读回原结果，新的发送重新引用当前页。无第二Runtime、Provider、依赖或文件路径IPC。

验证采用既有合同/集成测试及同一打包Electron探针，覆盖页面/工作区/窗口隔离、原文与选区、旧修订、超限、未知回执、幂等、重开及紧凑/展开/最小化。模型为MOCK_ONLY；真实Provider、物理IME和律师体验分别记录。回退只撤销本卡行为，保留已有Run及新字段的读取兼容，不覆盖原件或旧修订。

只参考用户截图以及 [Linear Agent](https://linear.app/docs/linear-agent)、[ChatGPT 文件上传](https://help.openai.com/en/articles/8555545-uploading-files-and-audio-to-chatgpt) 的交互概念，没有复制源码、安装依赖或引入其后台服务。
