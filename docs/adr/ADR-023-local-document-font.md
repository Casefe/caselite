# ADR-023｜本地文档字体与系统界面字体

状态：提议；DEV-1624 本次字体增量，2026-11-08 用户明确授权。工程证据与律师体验接收分别记录。

## 问题与决定

界面优先系统字体；可编辑文档/草稿使用官方思源宋体简中字形可变字体。既有 Tiptap/Yjs 内核、内容与修订、Application、保存和权限 Owner 保持。PDF 原页、文字层及标准后备字体不改。

采用未经改写的 Adobe 发布 WOFF2，固定来源提交、hash 和 OFL 许可见 `apps/desktop/assets/fonts/source-han-serif/README.md`。使用一个可变字重文件，暂不裁成常用字子集。独立复核发现它不含 U+20000，故以 CC0 的 Jigmo2 补充第二辅助平面字形（包括本次姓名字 𠮷 和扩展字 𠀀）；仅转换 WOFF2 容器，不裁剪字形，来源及 hash 见 `apps/desktop/assets/fonts/jigmo/PROVENANCE.md`。CSS `unicode-range: U+20000-2FFFF` 限定补充字体，普通中文仍命中思源宋体。字体和原始许可/声明由既有 Webpack 发射到本地资源，不增加运行依赖、安装脚本或网络服务。

CSP 仅新增 `font-src 'self'`，开发与打包一致；不允许远程字体、data/blob 字体或扩大脚本权限。正常界面不接收通用调试、任意字体路径或字体上传入口。字体加载失败有 serif 后备，缺字可使用系统后备；不声称覆盖所有汉字。

## 候选与验证

保留全部系统字体最省包，但文档视觉随设备变化。仅常用字裁剪可减包，但可能丢失姓名字；本轮未选。原始 PDF 换字体会改变原页，故不采用。

复用现有受校验的临时 demo 根，固定合成 Task 经 Application 创建、编辑器实际输入/保存/重开；本机合成凭据、运行拒绝派发、HTTP(S) 拒绝，不读真实案件/密钥。探针只接受固定 phase，使用宿主内部 debugger，不开放调试端口或新增 IPC。前后使用同一探针，检查实际字体/字形、PDF canvas 摘要、字节身份和包体；截图为真实打包 Renderer 的固定测试视口，不冒充律师接收。Chromium 的 glyphCount 会统计缺字方框，不能单独作为通过依据；补充字必须命中 Jigmo2，并独立核对样本 cmap 非零及非 .notdef 轮廓。基线只记观察，不伪称缺字通过。

## 后果与回退

思源宋体约18.83 MiB，另增加补充字库和原始声明，实际 App/ZIP 增量按同条件构建测量，不从原字体目录大小推断。为姓名覆盖保留完整 SIP 字库，未采用仅测试字的子集。后续字库裁剪、跨平台、字体嵌入与 Word/PDF 导出分别验证；不承诺第三辅助平面或所有异体字。回退仅撤销样式、资源和必要 CSP 增量，不转换 Yjs、不删除旧修订、不修改原件。
