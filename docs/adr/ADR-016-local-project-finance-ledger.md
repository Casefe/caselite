## 结构与事务

沿用项目所在 SQLite 连接。0015 追加账本表，不重写现有项目、任务或正文。一个项目登记一份有效人民币固定收费合同，所有正数金额以可精确表示的整数分存储。Application 用整数核对分期合计。确认收款分配到单一期款，冲回记录关联原收款并按原金额抵销。归档项目的账本可读。

项目列表和分期详情共享有效回款计算式。无合同返回空值，结清返回零。详情用宿主机当前时区的自然日计算到期，包含当日，并显示口径。查询无单独的余额存储。

写入经受信任窗口的类型化 IPC 和 Application。事务在核对归属、剩余金额和幂等键前取得写锁，同步登记账本、活动与回执，完成读回校验后才返回。只读核对用工作区、项目和原键，校验提交所对应的对象及活动，返回最小证据。已提交操作的读回显示当前账本。遇到未知回执时，界面先查原键。确认无回执后才由用户明确同键重试。关闭进程会丢失界面中的待核对请求，重开先查账本和历史。
