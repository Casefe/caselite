# ADR-005｜第三方代码、许可证与 Clean-room 实现规则

- 状态：已决定
- 日期：2026-10-30
- Linear Issue：[DEV-1558](https://linear.app/logixy-ai/issue/DEV-1558)
- 影响模块：全部仓库、依赖准入与未来发布物
- 代码位置与提交：规则文件；尚不表示许可证报告已生成

## 背景与问题

CaseLite 是公开仓库。开源项目可以作为架构研究对象，但目录形状、代码片段和功能相似性不赋予复制或重新发布的权利。

## 必须满足的不变量

- 不复制未明确许可的代码；尤其不将 AGPL 或商业项目实现混入本仓库。
- 任何拟复用源码须记录来源仓库、文件、提交、许可证、修改和 NOTICE 要求，并先取得人工确认。
- 新 npm 依赖须经过用途、许可证、维护、原生代码、数据外发与移除成本审查；P2/P3/P4 依赖受 DEV-1569 门禁。

## 候选方案

| 方案 | 结论 | 原因/证据 |
| --- | --- | --- |
| 阅读公开源码后以自身合同独立实现 | 采用 | 可保留研究价值，同时避免把参考实现误当作可复制资产。 |
| 复制参考项目的文件或目录结构并改名 | 放弃 | 许可证、NOTICE 与维护责任不可由“改名”消除。 |
| 每个小功能新装一套框架 | 放弃 | 增加攻击面、维护和退出成本。 |

## 验证与交付

- 已验证：当前仓库未加入任何参考项目源码；本 ADR 与 `docs/SECURITY.md` 约束一致。
- 待 DEV-1559 / DEV-1569：依赖审计、秘密扫描、许可证报告和准入记录。
- 回退：移除未经批准的依赖/代码，并按适用许可证处理 NOTICE 与历史风险；必要时停止公开发布并人工评估。

## 后果与重新评估条件

选择项目许可证、引入 copyleft 依赖、复制源码、发布二进制或生成第三方许可证报告前，必须单独审查并记录人工决定。
