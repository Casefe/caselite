# ADR-024｜固定快照的本地 Word 草稿导出

- 状态：已实现并完成本地技术验证与独立复核，待业务验收。

继续使用task:v1及原task_receipts，不引入第二运行时、正文系统或数据库。新操作仅接受当前作用域的task/document/snapshot ID，不接收路径、HTML、实时正文或输出hash；宿主从固定修订重新读取并校验hash。未知节点或不支持的属性明确失败，不静默遗漏。

新依赖精确准入docx 9.15.3（官方dolanmiu/docx，MIT，npm完整性sha512-3FnU6K5cuvGXEAn24yhvP3mfrZ1G8k9+hH8pSVDYsMR+mGmfK/t0NR5AwoMQodnaaxiRt2e+SvckffcJe/NvTQ==，Node>=16）。仅主进程Worker使用其公开API，禁止网络/外部转换服务；不复制Docmost EE或未知许可源码。保留依赖许可，独立审阅新增准入项与锁文件并运行安全检查。用现有Yjs校验和Worker机制，限制输入规模、内存、生成时长与输出大小。

0018增量迁移增加ExportArtifact：snapshot+format+converter版本唯一，固定输出hash与字节数，pending→ready。先持久预留身份，生成后记录预期hash，再以临时文件fsync和不覆盖的落位发布。最后同一SQLite事务提交ready、原幂等回执及业务活动；文件与SQLite之间中断后只核对同一受管产物，不能把半成品报成功。未知回执先读原键；生成成功后仅重复读取或打开，不重新生成。既有快照/原正文均不改写。

输出存于受管导出目录，renderer仅持opaque ID和显示元数据。打开Word前复核产物hash，建立独立工作副本（非符号/硬链接），外部编辑不会回写受管产物、快照或原件。工作副本同名重开不覆盖用户编辑；系统打开失败单独报错，不将其当作导出失败而重复生成。所有输出明确标草稿；不等于定稿、任务完成或发送。

本卡只实现Word；PDF仍禁用。来源清单沿快照当前空清单，不伪造引用。支持现行正文的中文段落、标题、列表、基础合并表格和文字标记；复杂或未知节点拒绝。验证旧快照/新版隔离、新键与原键重放、跨域/错版本、生成失败、落位/事务故障恢复、外部编辑原产物不变及真实Word打开。机器回读与律师业务验收分别记录。

回退保留0018、已生成文件、回执及读取兼容；可关闭新生成入口，不在原库直接降级或清除旧产物。在隔离副本核验备份恢复点。

转换边界：非默认单元格列宽/非左对齐、嵌套或缩进中的表格本卡明确拒绝；不声称Word排版保真。输入上限2MB、30万字符、2万块、16层转换嵌套，Worker内存192MB/15秒、输出20MB；规模/不支持格式显式失败。Mammoth不保留编号起始值，编号另外核对OOXML numId/override并在原生Word观察。
