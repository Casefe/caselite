# ADR-020｜本地任务视图与项目计划

- 状态：提议，等待迁移与原生验证
- 责任卡：DEV-1605、DEV-1603、DEV-1598
- 基线：8e1e920，CaseLite 现行 02 和 06

本轮增加个人工作区内的任务视图和项目计划。任务、项目、正文及归组仍由各自原有 Owner 管理。

- 创建视图使用本机成功创建事件及其时间。没有创建证据的历史记录不推断作者。订阅为当前单用户工作区的任务偏好，旧任务默认关闭，本机新建任务默认订阅。写入走原 Task 接口、回执和活动事务，订阅不修改正文修订。
- 相邻任务按进入详情时的筛选与排序重新查询，越界、任务退出筛选或来源读取失败时不猜测相邻目标。返回列表仍使用原导航状态。
- 进度从实际任务状态推导。健康度由人工在项目更新中确认。里程碑归项目所有，任务可选关联同一项目的一个里程碑，归组变更不得跨项目留下关系。
- 继续使用本地 SQLite 和受控 IPC。团队身份、同步通知、法定期限算法和预测进度留在各自责任卡。

迁移为增量。回退应用代码时保留新列、关系和本地记录；不执行降级删除。以旧库升级、事务负例、原生重启和回跳作为接收证据。
