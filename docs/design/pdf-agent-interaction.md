# 首页 Agent 的资料交互合同

用户结果：添加 PDF，说明要完成的工作，发送后得到可核对的回答，并可以在空输入框开始下一轮。

## 正常路径

1. 拖入或点击加号选择 PDF，立即显示附件卡；输入目标与导入并行，不要求选择文件夹、保存方式、OCR引擎或勾选纳入。
2. 一次点击发送提交本轮附件与要求。发送时系统负责等待这些附件可读；无关文件的后台任务不应阻塞已可读附件的分析。
3. 发送被可靠接收后，附件卡移入消息记录，清空本轮输入。文件不是被删除；点击消息附件可阅读原件。迟到回执不能清除后来输入。
4. 准备、发送、生成均显示简短状态与取消入口。异常保留可恢复的输入及原件，未知回执按同一标识核对，不能自动再收费。

这里“文件自动消失”指离开待发送输入框。仅添加文件但尚未发送时仍显示附件，便于用户确认分析对象。

## 自动处理决策

- 普通文字 PDF 直接提取文字，避免无必要的 OCR 与图像输入成本。
- 视觉模型读取扫描页原图并同次完成分析；即使已有本地OCR候选，也优先原图，不把识别错误固化为本次事实。
- 当前文字模型自动用本地OCR。保持用户已选择的模型，不因文件类型静默切换服务商。
- 受管保存、来源登记、归档由后台完成。检索索引等后续能力不得成为回答的前置条件；已经实现和规划能力分别留证。
- 不增加独立收费的云端OCR调用。图像输入仍有模型费用；“减少操作”不等于已验证“最快或最便宜”。
