# 任务字段设计｜Linear 参考

2026-11-06，用户要求任务字段和新建界面参考 Linear。本页是设计对照，不代表所有字段已经实现或通过验收。现行合同和具体责任以 Linear 的 [DEV-1577](https://linear.app/logixy-ai/issue/DEV-1577)、[DEV-1582](https://linear.app/logixy-ai/issue/DEV-1582)、[DEV-1600](https://linear.app/logixy-ai/issue/DEV-1600) 与 [DEV-1601](https://linear.app/logixy-ai/issue/DEV-1601) 为准。

Linear 的新建 Issue 将标题、说明与状态、优先级、负责人、项目和标签分开呈现；其产品默认使用团队及工作流。CaseLite 采用清晰的属性布局，继续允许无账号、无项目创建独立任务，不复制团队或其工作流。参考：[Linear Issues](https://linear.app/docs/creating-issues)、[Linear Priority](https://linear.app/docs/priority)。

| 字段           | CaseLite 设计及权威位置                                                      | 当前实际情况                     |
| -------------- | ---------------------------------------------------------------------------- | -------------------------------- |
| 标题           | 必填，Task 元数据，最多 160 字符                                             | 已支持创建和读取                 |
| 任务说明       | 可选，复用统一富文本及 Yjs；结构化目标与说明正文的权威边界按现行合同         | 现有创建和重开路径可用           |
| 状态           | 普通工作状态：待办、进行中、完成、取消；不与 AI 运行、法律定稿或交付状态混用 | DEV-1600，未接入                 |
| 优先级         | 可选；参考 Linear 的无、低、中、高、紧急，实际枚举与转换由 DEV-1601 冻结     | 未接入                           |
| 截止日期       | 可选、用户指定的普通日期，不自动视为法定期限；提醒单独准入                   | DEV-1601／DEV-1686，未接入       |
| 负责人         | 单人阶段默认本人；成员身份和后续协作授权由相应 Owner 明确                    | 真实人员分派未接入               |
| 项目           | 可选，使用既有 Matter 关联；不因项目归组扩大 AI 输入或权限                   | 现有目录支持归组；新建表单未接入 |
| 标签           | 候选分类属性；身份、范围、管理和权限尚待对应消费者设计                       | 未接入                           |
| 稳定身份与修订 | Task ID、对象版本、正文绑定与修订分别保存，避免重复创建或覆盖旧内容          | 已有最低合同及保存链路           |
| 创建／更新时间 | 由存储端管理；排序和展示须定义稳定语义                                       | 当前仅持久化更新时间             |

创建表单当前仅展示并提交真实可用的标题和说明。新增字段应由相应 Issue 串行扩展同一 Task Owner，经类型化 IPC 和 Application 验证，并覆盖旧数据、幂等、失败、重启及必要的数据库迁移、备份和独立复核；不得用界面状态冒充已保存字段。附件、模板、团队、周期和多负责人不因 Linear 截图自动纳入本期。
