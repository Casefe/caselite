# 创建与附件交互约定

来源：DEV-1883 与 2026-11-11 用户确认的任务/日程 V2 模拟图。产品范围以 Linear 现行合同为准，本页只维护工程复用边界。存储决定见 ADR-035。

## 分层与职责

创建界面采用公共交互构件、领域表单、受控保存动作三层组合。公共部分统一标题/说明布局、按钮、焦点恢复、中文输入法与快捷键保护、草稿退出、附件状态和错误呈现。领域表单提供字段、默认值、条件字段与校验；Application 负责范围、权限、幂等、事务、落盘和回执。界面只投影这些结果，不直接读写文件或数据库。

“读写一致”指同样遵守受控入口、真实保存确认、原键恢复和失败保全，不表示六类对象共用一张表或一条万能保存命令。字段并非唯一差异：财务入账、联系人去重、Document/Yjs 修订与 Task 创建分别有自己的规则。

| 类型   | 领域组件与 Owner                                        | 本轮接入情况                                             |
| ------ | ------------------------------------------------------- | -------------------------------------------------------- |
| 任务   | TaskCreateDialog → 原 Task Application/Store            | 任务页、项目内与日历引用同一表单；日历预填可清除的计划日 |
| 日程   | 同一 TaskCreateDialog 的时间优先布局 → 原 Task 日历字段 | 标题、同日日期/起止时间、IANA 时区；不是第二日程对象     |
| 项目   | ProjectCreateDialog/ProjectFields → Catalog Application | 保留原实现，本轮不重写或新增项目附件语义                 |
| 文档   | 原 Document 创建/正文入口 → Document/Yjs Owner          | 后续按具体 Issue 引用公共交互构件，正文和修订规则独立    |
| 财务   | 原 Finance 表单 → Finance Application                   | 入账类型、金额、币种与项目关系按原合同；本轮不改         |
| 联系人 | 原 Contacts 表单 → Contacts Application                 | 身份、关系和校验按原合同；本轮不改                       |

## 附件

独立基础组件 shared/ui/FileUpload 只接收文件列表、显示状态、限制说明和选择/移除动作，不引用 Task、领域接口、预加载 API 或绑定/保存/恢复代码。各领域适配层提供权限、格式/大小/数量/范围校验、暂存、绑定、保存和恢复。AI 可复用基础上传交互，但选材、输入类型、预算与发送确认仍由 AI 适配层处理；不能因上传就自动发给模型。

本轮 Task/日程适配位于 features/tasks/CreationAttachments 与 useTaskCreationAttachments；真实文件与版本继续归原 Material Application、MaterialFilesPort 和 material_stages。格式和单份上限由原 contracts/material 经预加载只读投影提供，不在页面重新写另一组常量。基础组件不决定六类对象是否允许附件，也不扩大现有写入范围。

新建中每次选择一份文件，可逐次追加，不恢复批量/文件夹按钮。选择后显示文件名、大小和待保存状态；选文件不创建隐藏 Task、不自动选为 AI 材料。点击创建时，同一事务建立 Task、日历字段、附件绑定与根回执，再沿原 token 逐项保存原件。只有真实确认后显示已保存；部分失败保留同一 Task 与附件，继续保存不重复创建。重启可恢复未完成附件。

取消选择器保留输入；移除只清理本草稿未提交暂存；关闭脏表单先确认。任务已创建或根结果未知时，继续原提交，不将取消按钮解释成删除 Task。普通日期、日程时段、提醒和重要标记分别保存。上传不自动触发云端操作。

## 扩展与检查

新入口引用既有领域表单，差异以类型化初始值或明确布局变体提供。出现新的真实消费者时，再提取已重复的公共结构；不预建六套适配器或给所有字段加配置引擎。新的附件目标范围必须先由对应 Application 准入，不能仅传一个 ID 即扩大读写能力。

共享行为须覆盖键盘/焦点/IME、取消、重复提交、部分失败、未知回执、逐项恢复、正常重开和窄窗；字段与领域写入用各自合同测试验证。设计稿、合成运行和律师接受分别记录。不得用提示词或文档存在代替运行证据。
