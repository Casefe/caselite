# CaseLite｜产品范围与用户结果

本页为现行01—06的公开开发摘要，入口见 [SOURCES](SOURCES.md)，不复制任务状态或替代实时合同。旧 v2.2 的 Matter 优先、P0—P4 排期不再决定当前实施顺序。

## 用户工作路径

服务独立律师和小团队，以独立 Task 开始。首个代表任务是“梳理两份材料中的事实、矛盾和缺件，形成律师内部沟通初稿”。当前先验证无需账号和 Key 的 Task／正文保存与重开，再接入材料、真实 BYOK、核对和交付。Task 可持续补材料和多次运行，可选加入项目；项目不成为开始工作的前置。

| 交付阶段 | 用户可完成的结果 | 结束边界 |
| --- | --- | --- |
| 开发准备 | 代表样本、最低合同、当前工程基线及独立交接可复现 | 独立预演、适用失败恢复及人工接收分别记录；开发工具另轨 |
| 单任务生产 | 选材导入、阅读、标注摘录、检索选定材料、人工或AI起草、核对、保存与交付 | 干净内部安装、离线人工、真实BYOK、同一快照Word／PDF实际打开；本变体承诺扫描件，须验证本地OCR |
| 持续任务与项目 | 追问、补材料、多次Run、项目归组、待办和重要日期 | Task ID、来源与历史不变；日期／时区由用户确认，提醒实际覆盖范围明示 |
| 独立审查与复用 | 对照材料、规则检查、问题表、模板与受控知识 | 问题回原文、报缺；用户选择沉淀。专业事实和法定期限另有合同 |
| 个人双设备 | 另一设备读写选定资料，离线后恢复 | E2EE、冲突、丢失设备恢复及退出后的本地可用性 |
| 小团队 | 2—5人选定事项邀请、分派、异步评论或修改、共享知识 | 权限、撤权、交接和恢复；实时同编依真实需求准入 |

以上是交付目标，不是已实现清单。候选和增强按独立责任卡准入，不把全部候选提前变成首发门槛。

## 不变量

- 个人已实现的本地工作无需登录；关闭网络、AI或协作不应破坏已有本地数据。
- SQLite 管结构化对象，Yjs 二进制管正文，不可变 AssetVersion 管原件；预览／索引可重建，不另建真源。
- 原文、OCR候选、个人备注、模型文字和律师确认区分；缺件、矛盾及无依据不能写成已查明。
- 本地保存、模型成功、候选接受、正式定稿、导出、实际外发及Task完成分别表达。
- 用户明确选择材料和本次外发范围。项目归组不自动扩权；不默认全库上传或发送全部历史。
- 个人核心免费与同步协作增值为产品方向；不据此承诺未验成本比例或已上线服务。
